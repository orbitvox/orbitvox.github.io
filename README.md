# orbitvox.github.io

The website for [OrbitVox](https://github.com/orbitvox/orbitvox), a local voice for your AI agent.

This repo only holds the static landing page served at https://orbitvox.github.io. The code, issues and security policy live in [orbitvox/orbitvox](https://github.com/orbitvox/orbitvox). Report security problems there, privately: see its [SECURITY.md](https://github.com/orbitvox/orbitvox/blob/main/SECURITY.md).
